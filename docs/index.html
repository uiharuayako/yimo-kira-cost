建模假设

公示之外，明确约定

  • 只抓普通伊莫，排除头目；所有成功捕获都符合幸运判定条件，状态系数为 1。
  • 初始虹能、本周普通 / 超级次数、两类保底计数均为 0；先完成 n 次滋养，再开始捕获，全程不跨周。
  • 两类保底各自累计，仅触发本类时重置；超级触发当次普通判定与普通保底计数暂停。
  • 幸运的 0.6% 与精华滋养的 3% 直接虹天气都不提前停止，也不替代或重置本模型中的虹能奖励（含每次滋养 +480）；目标严格为累计虹能 ≥10,500。
  • 每次投掷的正背面、捕获与后续幸运事件按所给概率独立处理。

官网未完整说明双保底计数的实现细节，以及直接虹天气对虹能进度的影响；本页使用以上明确约定。若实际游戏规则不同，虹能模型的期望次数需要重新计算。
