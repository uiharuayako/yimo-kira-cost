# 伊莫 · 虹能捕捉成本计算器

比较谜立方、超级立方、究极立方，从零累计到 **10,500 虹能**的期望立方金币花费。提供 15 种区域 / 成长阶段权重、两种权重口径、地脉精华滋养次数、捕获概率分支、幸运与保底过程、可读的数学公式和逐项数据来源。**精华自身成本未计入金币结果。**

在线使用：<https://uiharuayako.github.io/yimo-kira-cost/>

## 本地运行

需要 Node.js 22.12 或以上版本。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173/`。页面和公式字体均从本站加载；不依赖外部 CDN，不向服务器上传权重。浏览器会在本机保存最后使用的配置。

## 计算口径

- 全部在战斗外捕捉普通、非头目伊莫；等级差 ≤10，其他状态系数为 1。
- 每次投掷独立有 70% 正面、30% 背面，背袭系数 1.5。
- 特殊加成为每个分支的最终捕获率 **+1 个百分点**，再限制到 100%。这是用户指定条件，不是对官网联结者加成公式的转述。
- 三种立方价格为 3,500 / 7,000 / 10,500 金币，来自用户指定条件；倍率 1 / 1.5 / 2 来自官网。
- 失败消耗立方，但不推进幸运判定；所有成功捕获均符合幸运判定条件。
- 初始虹能、本周普通 / 超级幸运次数和两类保底计数均为 0，在本周刷新前完成。
- 先判超级，未触发才判普通；各类保底分别计数、只在触发本类时重置；超级触发当次暂停普通判定与普通保底累计。最后一项是官网未完全说明的建模假设。
- 地脉精华滋养次数 `n` 为非负整数，默认 0。先使用 `n` 次精华，每次按官网直接获得 480 虹能；剩余捕捉目标为 `max(10500 - 480 × n, 0)`。`n ≥ 22` 时无捕捉需求，立方费为 0。精华自身成本不在本工具的金币结果中。
- 严格在累计虹能 ≥10,500 时停止。幸运的 0.6% 和精华的 3% 直接虹天气均不提前停止，也不替代 / 重置本模型的虹能奖励；官网没有完整说明这种交互，结果依赖该假设。

对基础率 `b`、立方倍率 `m`：

```text
p_front = min(b × m + 0.01, 1)
p_back  = min(b × m × 1.5 + 0.01, 1)
p       = 0.7 × p_front + 0.3 × p_back
```

设归一化权重为 `αᵢ`，在当前精华次数下的成功捕捉次数期望为 `Kₙ`，立方单价为 `c`：

```text
投掷目标占比：p_eff = Σ αᵢpᵢ
成功捕获占比：p_eff = 1 / Σ(αᵢ / pᵢ)
期望用球数： Kₙ / p_eff
期望立方费： c × Kₙ / p_eff
```

“成功捕获占比”表示选择某类目标后抓到成功，再换下一只；“投掷目标占比”表示每次投掷重新按占比选择目标。不能用平均基础率代替逐类计算，因为每个正 / 背分支会分别触顶。

## 虹能次数估计与来源

[《伊莫》官网概率公示](https://www.yimo.com/formula-multipliers)，核对日期 **2026-10-30**。网站区分「官网公示」「用户给定」「模拟结果」「建模假设」，每条主要公式附符号、单位和来源。

在默认 **0 次滋养**时，两套事件跳跃实现共 15,000,000 条路径：

| 路径数 | 随机种子 | 成功捕捉次数均值 |
| ---: | ---: | ---: |
| 5,000,000 | 20261030 | 2797.9834930 |
| 10,000,000 | 2026103017 | 2797.6725343 |
| 合并 15,000,000 | — | **2797.7761872** |

合并均值的标准误约 0.162895，95% 蒙特卡洛置信区间约 `[2797.4569133, 2798.0954611]`。该区间反映**模拟均值估计误差**，不是单个玩家的 95% 费用范围，也不包括模型规则的不确定性。另用逐次捕获实现交叉核验了停止时间。

对 1～21 次滋养，按每个剩余虹能门槛分别估计停止时间，**不按剩余虹能比例缩放原 K**。共享同一批模拟路径，在路径依次越过各个门槛时记录成功捕捉次数，各门槛均从本周幸运次数和保底计数为零开始。详细样本量、种子、均值和置信区间见 `data/essence-results.json`。网页使用预先计算的查表值，切换精华次数或权重不在浏览器执行大规模模拟；权重变化不改变当前虹能门槛的 K。

默认仅后期区域·成熟期权重为 1：

| 立方 | 捕获率 | 期望消耗 | 期望金币 |
| --- | ---: | ---: | ---: |
| 谜立方 | 19.4% | 14421.5 | 5047.5 万 |
| 超级立方 | 28.6% | 9782.4 | 6847.7 万 |
| 究极立方 | 37.8% | 7401.5 | 7771.6 万 |

详细模型数据在 `data/`，纯计算在 `src/model.js`，可选复算脚本在 `scripts/`。模拟需要 Python 与 NumPy，不是网站运行依赖。

## 发布到 GitHub Pages

`npm run build` 生成并覆盖项目内部的 `docs/`。Pages 的发布源为 `main` 分支的 `/docs` 目录。修改后先运行测试和构建，再一并提交源文件与 `docs/` 并推送，GitHub 将重新发布。

这是静态网站，无后端和 API 密钥。公式排版使用本地打包的 [KaTeX](https://katex.org/)，第三方许可证保留在 `docs/vendor/katex/LICENSE`。
